# 🎓 Learning Management System (LMS) 
A dynamic, full-stack educational platform designed to streamline classroom management, assignment tracking, and academic performance monitoring. This system provides a seamless interface for students to manage their learning journey and for instructors to handle grading and course administration efficiently.

## 📝 Project Description
The LMS is an all-in-one web application built to bridge the gap between students and instructors. It offers a centralized dashboard where students can track their course progress, view upcoming deadlines, and monitor their grades in real-time. For instructors, the system provides a secure, role-based environment to manually input grades, manage student IDs, and oversee course assessments.

## ✨ Key Features
 ->Intuitive Student Dashboard: A comprehensive overview of enrolled courses, current GPA, and pending tasks with visual progress indicators.

 ->Dynamic Grading System: Automated calculation of overall averages and GPA based on instructor-inputted data.

 ->Assignment Management: Real-time tracking of pending, urgent, and completed assignments with automated status badges.

 -> Role-Based Access Control (RBAC): Secure login logic that differentiates between Student and Instructor permissions.

 ->Interactive Gradebook: A detailed table view for students that joins course progress data with academic scores for full transparency.

 ->Responsive Experience: Fully optimized for all device types using Bootstrap’s grid system and components.

## 🛠️ Technical Implementation
 ->Backend Logic: Developed using PHP for robust server-side processing and session management.

 -> Database Management: Utilizes MySQL with complex relational queries (JOINs) to synchronize student progress and grading records.

 ->Frontend Interface: Crafted with HTML5, CSS3, and JavaScript, leveraging Bootstrap 5 for modern UI/UX components.

->Security: Implemented prepared statements to prevent SQL injection and secure session-handling to protect user data.

## 🎯 Project Impact
 This system replaces traditional manual tracking with a dynamic database-driven solution, reducing administrative overhead and providing students with immediate feedback on their academic performance at Hawassa University.
